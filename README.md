# Avaliação Técnica de Lógica e Desenvolvimento

Este repositório contém a solução completa para a avaliação técnica, organizada em pastas separadas para cada questão e exercício prático.

## Estrutura do Repositório

- **README.md**  
  Arquivo principal com as respostas detalhadas das perguntas de lógica (1 a 6), incluindo exemplos e explicações.

- **01-webhook-leads-fastapi**  
  Projeto FastAPI + PostgreSQL para mapeamento e armazenamento de leads. Inclui exemplos de requisição e script de teste.

- **02-fanout-apis-fastapi**  
  Projeto FastAPI que envia dados para múltiplas APIs, registra erros e segue o fluxo. Inclui exemplos e script de teste.

- **03-bulk-sender-fastapi**  
  Projeto FastAPI para envio de leads em lotes, garantindo que todos sejam enviados sem repetição ou perda. Inclui exemplos e script de teste.

- **04-compare-equality-js**  
  Exemplo em JavaScript mostrando a diferença entre `==` e `===`.

- **05-sort-desc-js**  
  Exemplo de ordenação manual de array em ordem decrescente, com explicação sobre algoritmos de ordenação.

- **06-clean-object-js**  
  Função JavaScript para remover propriedades `null` ou `undefined` de um objeto.

- **07-catalogo-paises-fastapi**  
  Exercício prático: API completa para catálogo de países, com listagem, busca e avaliação. Utiliza FastAPI, PostgreSQL e consumo da REST Countries. Inclui scripts de teste para cada endpoint.

## Sobre o Exercício 7

O exercício 7 é prático e demonstra o uso de FastAPI, integração com API externa, persistência em banco de dados e organização de endpoints.  
Além do código, há um vídeo explicativo mostrando os desafios enfrentados, as soluções aplicadas e exemplos de funcionamento da API.

## Como usar

Cada pasta contém um arquivo `README.md` próprio, com instruções de uso, exemplos de requisição e explicações sobre a solução implementada.

Para dúvidas ou sugestões, fique à vontade para abrir uma issue ou entrar em contato!
